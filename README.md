Description- CAPSTONE 3
This project is a web application that allows users to interact with Pokémon data fetched from the PokéAPI. It displays a list of Pokémon with their images and names, and provides a modal where users can view additional details like height, weight, and official artwork. Users can "catch" a Pokémon, saving it in the browser's local storage, or "release" a Pokémon, which removes it from the list of caught Pokémon. The app also supports pagination, enabling users to load more Pokémon by clicking the "Load More" button. The application is fully responsive, providing a seamless experience on both desktop and mobile devices. It is built using HTML, CSS, and JavaScript, with no page refreshes and all interactions handled dynamically. The use of local storage ensures that caught Pokémon are retained even after a page reload. This project demonstrates a simple but interactive way to explore and manage Pokémon data in a user-friendly web application.
